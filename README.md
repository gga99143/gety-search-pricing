## Gety 到底能搜什么，搜不到什么

第一次启动时它会索引整个硬盘，几分钟后就能开始搜，之后的每次搜索在毫秒级返回结果。文件有改动会自动检测，索引增量更新，不需要你手动重建。搜索结果按相关度排序，最相关的内容排在前面。

真正拉开差距的是对图片类文件的处理。扫描版 PDF、截图、照片里的文字本质上是图像，传统搜索工具拿它们没办法。Gety 内置了一个自研的本地 OCR 引擎，装完就能用，索引时自动把图片里的文字抽出来，之后按普通文档搜就行。网页截图和聊天记录能认，扫描合同也行，倾斜或扭曲的文档同样处理得了，中英文混排不成问题。新产生的截图和扫描件也会被自动识别并抽取。

搜到之后，预览是按原始文档渲染的，表格和版式都保留，不会像有些工具那样只抽纯文本、把排版拆得面目全非。打开结果会高亮命中的段落，右上角显示命中数量，用上下箭头在多个命中之间跳转。

它还有一层用法是给 AI 当检索层。AI 工具虽然能读本地文件，但让它每次任务都从零扫一遍全盘，既慢又费 token，还得给它全盘访问权限。Gety 通过 MCP、API 或 CLI 被 AI 调用，把最相关的片段在毫秒内返回去当上下文。默认只返回你许可的片段，配合本地模型可以完全离线运行。连接器还能把浏览器历史、Notion 和飞书这类云端数据接进来。
